DRAFT MENU FIXES

Close the game. Back up the three files before editing.
Use Notepad++ or Visual Studio Code. Keep UTF-8 and the existing line endings.
Use your own Space folder if the game is installed elsewhere.
Apply each step once. If REPLACE WITH is already present, skip that step.

1. READY BUTTON

Open:
C:\Program Files (x86)\Steam\steamapps\common\Space\spacegame\Content\UIResources\frontend\drafting\drafting-script.js

Find the condition inside function setDraftingState(state).

FIND:
if (state == DRAFTING_STAGES.WaitingforUsers || state == DRAFTING_STAGES.BalancingTeams) {

REPLACE WITH:
if (state == DRAFTING_STAGES.BalancingTeams) {

2. MODE NAMES AND ARTWORK

Open:
C:\Program Files (x86)\Steam\steamapps\common\Space\spacegame\Content\UIResources\frontend\drafting\mode-selector.js

A. Mode constants

FIND:
    CONQUEST: 'conquest',

REPLACE WITH:
    CONQUEST: 'conquest',
    CONQUEST3V3: 'conquest3v3',
    FRONTLINE: 'frontline',

B. Mode name matching

FIND:
      switch(mode.Name) {

REPLACE WITH:
      switch(mode.Name.toLowerCase()) {

C. Mode labels

FIND:
        case MODES.CONQUEST:
          l10n = utils.l10n.get('GameModeConquestLabel');
          break;

REPLACE WITH:
        case MODES.CONQUEST:
          l10n = utils.l10n.get('GameModeConquestLabel');
          break;
        case MODES.CONQUEST3V3:
          l10n = utils.l10n.get('GameModeConquest3v3Label');
          break;
        case MODES.FRONTLINE:
          l10n = utils.l10n.get('GameModeFrontlineLabel');
          break;

D. Artwork selection

FIND:
ModeSelector.prototype.TEMPLATE_MODE = function templateBuilder(name, id, l10n, rewardBonusObj) {

REPLACE WITH:
ModeSelector.prototype.TEMPLATE_MODE = function templateBuilder(name, id, l10n, rewardBonusObj) {
    let modeName = name.toLowerCase();
    let imagePath = modeName === MODES.FRONTLINE
      ? './views/gamemodes/images/medium/solo-frontline.png'
      : './drafting/modes/' + (modeName === MODES.CONQUEST3V3 ? MODES.CONQUEST : modeName) + '.png';

E. Artwork image

FIND:
background-image: url(./drafting/modes/${name}.png);

REPLACE WITH:
background-image: url(${imagePath});
